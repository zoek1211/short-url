# 04: 번호 해석과 404 안내 화면

**What to build:** 존재하지 않는 번호나 올바른 번호 형식이 아닌 주소를 열면, 백엔드가 알아볼 수 있는 한국어 404 안내 화면을 404 상태로 돌려준다. 하나의 링크에는 단축 주소가 정확히 하나만 존재한다.

**Blocked by:** 01 로컬에서 생성하고 이동하기

**Status:** ready-for-agent

- [x] 0으로 시작하지 않는 양의 정수이면서 DB 정수 범위 안에 있는 값만 번호로 인정한다
- [x] 존재하지 않는 번호는 404와 안내 HTML을 돌려준다
- [x] `/042`, `/0`, DB 범위를 넘는 큰 수는 404와 같은 안내 HTML을 돌려준다
- [x] 단축 주소에 붙은 쿼리(`/42?utm=x`)는 무시하고 저장된 원본 URL 그대로 302로 보낸다
- [x] 안내 화면에 생성 화면으로 돌아가는 링크가 있다
- [x] 위 경우마다 HTTP 경계 통합 테스트가 있다

## Comments

- 번호 해석은 `parse_number`(ASCII 숫자만, 선행 0 불가, i64 양수)로 수행하고, 실패/미존재 모두 `not_found_page`가 만든 동일한 한국어 HTML(404, `text/html; charset=utf-8`, 인라인 CSS, `PUBLIC_BASE_URL/` 링크는 HTML 이스케이프)을 반환한다. 쿼리 스트링은 라우트가 무시한다. 테스트: `backend/tests/not_found.rs`.
